# Эстетика старого веба и консолей в браузере

Современный интернет часто выглядит одинаково: белые карточки, одинаковые шрифты и бесконечная лента. Но в 90-е и нулевые у каждой домашней странички был свой характер.

## Что удалось собрать на сайте
* **Эпоха консолей:** NES 8-Bit, Sega Genesis 16-Bit, PlayStation 1 BIOS и карманный Game Boy DMG-01.
* **Эпоха веба:** GeoCities '97, Cyber Realm, Y2K Millennium и Frutiger Aero.
* **Аналог:** VHS-телевизор и терминал Netrunner.

Весь код работает на чистом **HTML + CSS + JS** и Web Audio API — без сборщиков и тяжёлых фреймворков, чтобы сайт мгновенно открывался прямо с GitHub Pages.
